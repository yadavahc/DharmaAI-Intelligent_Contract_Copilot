# ─────────────────────────────────────────────────────────────────────────
# Lyzr multi-agent framework — installed SEPARATELY, with --no-deps.
#
#   pip install --no-deps -r requirements-lyzr.txt
#
# WHY --no-deps (this is deliberate, not a shortcut):
#
#   lyzr-automata==0.1.3 declares two hard pins:
#       openai==1.3.4     requests==2.31.0
#
#   The openai pin exists solely for `lyzr_automata.ai_models.openai.OpenAIModel`.
#   Dharma AI does not use that class — it supplies its own implementation of
#   Lyzr's `AIModel` ABC (backend/app/agents/model.py) built on the modern
#   OpenAI SDK, because we need JSON-mode structured output and token streaming
#   that the 2023-era pinned client cannot provide.
#
#   The import chain actually exercised by Dharma AI is:
#       lyzr_automata/__init__.py
#         -> agents/agent_base.py      (stdlib only)
#         -> tasks/task_base.py        (stdlib + lyzr internals)
#         -> tools/tool_base.py        (stdlib + lyzr internals)
#         -> pipelines/linear_sync_pipeline.py
#         -> logger.py                 (requests)
#         -> utils/resource_handler.py (requests)
#         -> data_models.py            (pydantic)
#
#   i.e. stdlib + `requests` + `pydantic`, both of which are already pinned at
#   modern versions in requirements.txt. `ai_models/openai.py` is never
#   imported, so openai==1.3.4 is never needed. Verified by import probe.
#
# WHY --ignore-requires-python may be needed:
#
#   The wheel declares `Requires-Python: >=3.8.1, <3.12`, but it is a pure
#   Python `py3-none-any` wheel with no version-sensitive syntax and imports
#   cleanly on 3.12/3.13/3.14. The Docker image uses python:3.11-slim, which
#   satisfies the declared range natively — no flag needed there. For local
#   venvs on newer Pythons:
#
#     pip install --no-deps --ignore-requires-python -r requirements-lyzr.txt
#
# If this install is skipped entirely, Dharma AI still runs: the agents module
# falls back to a signature-identical shim (agents/lyzr_compat.py) and reports
# `lyzr_runtime: "shim"` on GET /api/agents/runtime instead of "lyzr-automata".
# ─────────────────────────────────────────────────────────────────────────
lyzr-automata==0.1.3
